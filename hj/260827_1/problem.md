# N×N 격자 이동 및 방문 횟수

## 문제 설명

`N × N` 크기의 이차원 격자판이 있다.

현재 맨 **왼쪽 위 격자**에서 시작한다.

방향은 다음과 같이 정의한다.

* `N` : 북쪽 → 위
* `S` : 남쪽 → 아래
* `W` : 서쪽 → 왼쪽
* `E` : 동쪽 → 오른쪽

총 `Q`개의 명령이 주어진다.

각 명령은 다음과 같은 형태이다.

```text
D L
```

* `D` : 이동할 방향 (`N`, `S`, `E`, `W`)
* `L` : 해당 방향으로 이동을 시도할 횟수

명령 `(D, L)`이 주어지면 **D 방향으로 한 칸 이동하는 작업을 L번 반복**한다.

단, 이동하려는 방향에 격자가 존재하지 않는 경우, 해당 이동은 **무시한다.**

어떤 격자 `A`에서 다른 격자 `B`로 실제 이동했다면, 격자 `B`를 **1번 방문한 것**으로 센다.

모든 명령을 수행한 뒤, **2번 이상 방문한 격자의 개수**를 출력한다.

> 시작 위치는 이동해서 도착한 것이 아니므로 방문 횟수에 포함하지 않는다.

---

## 입력

첫 번째 줄에 격자판의 크기 `N`이 주어진다.

두 번째 줄에 명령의 개수 `Q`가 주어진다.

이후 `Q`개의 줄에 걸쳐 다음과 같이 명령이 주어진다.

```text
D L
```

---

## 출력

모든 명령을 수행한 후,

**2번 이상 방문한 격자의 개수**를 출력한다.

---

## 입력 예제

```text
3
3
S 2
N 1
E 1
```

## 출력 예제

```text
1
```

---

## 예제 설명

`N = 3`, `Q = 3`이다.

시작 위치를 `(0, 0)`이라고 하면 이동 과정은 다음과 같다.

```text
시작 : (0, 0)

S 2
(0, 0) → (1, 0) → (2, 0)

N 1
(2, 0) → (1, 0)

E 1
(1, 0) → (1, 1)
```

각 격자의 최종 방문 횟수는 다음과 같다.

```text
0 0 0
2 1 0
1 0 0
```

`(1, 0)` 격자만 총 **2번 방문**했으므로 정답은 다음과 같다.

```text
1
```

---

## 핵심 조건

1. 시작 위치는 방문 횟수에 포함하지 않는다.
2. **실제로 이동에 성공한 경우에만** 도착한 격자의 방문 횟수를 증가시킨다.
3. 격자 밖으로 나가는 이동 명령은 무시한다.
4. 한 격자를 여러 번 방문할 수 있다.
5. 최종적으로 방문 횟수가 `2 이상`인 격자의 개수를 구한다.
